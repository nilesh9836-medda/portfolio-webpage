A modern, responsive product landing page designed to present a product, highlight its key features, and encourage visitors to take action.

This project is a frontend product landing page created as part of my web development portfolio.

The page focuses on:

* Responsive design
* Clear product presentation
* Strong call-to-action sections

* Mobile and desktop compatibility

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/nilesh9836-medda/portfolio-webpage.git
```

### 2. Open the project

```bash
cd product-landing-page
```

### 3. Run the website

This is a static frontend project, so no backend or package installation is required.

You can open `index.html` directly in your browser, or use a local development server such as VS Code Live Server.
